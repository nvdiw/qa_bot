# QABot - ربات پاسخ‌دهی سوالات خودکار

یک ربات تلگرام هوشمند که پاسخ‌های سوالات را از فایل CSV بارگذاری می‌کند و به صورت خودکار به کاربران جواب می‌دهد.

## 🚀 ویژگی‌ها

✅ **جستجوی هوشمند**: جستجوی فازی (Fuzzy Search) برای یافتن بهترین تطابق  
✅ **مدیریت سوالات بدون جواب**: سوالاتی که پاسخ ندارند به مدیر ارسال می‌شود  
✅ **سیستم پاسخ‌دهی مدیر**: مدیر می‌تواند Reply کند و جواب ثبت شود  
✅ **ساختار ماژولار و تمیز**: کد سازمان‌یافته و قابل توسعه  
✅ **آمار و گزارش‌ها**: نمایش تعداد سوالات و جوابات  
✅ **پشتیبانی فارسی کامل**: تمام پیام‌ها به فارسی

## 📋 شرایط کار

- Python 3.9 یا بالاتر
- اتصال اینترنت
- Token از Telegram BotFather

## 🔧 نصب و راه‌اندازی

### 1️⃣ نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 2️⃣ دریافت Token و Admin ID

**دریافت Bot Token:**
1. به [@BotFather](https://t.me/BotFather) در تلگرام مراجعه کنید
2. دستور `/newbot` را بزنید
3. نام و یوزرنیم ربات را انتخاب کنید
4. Token را کپی کنید

**دریافت Admin ID:**
1. ربات را تکست دهید
2. لیبی حاوی شناسه کاربری خود را کسب کنید (از سایت `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates` استفاده کنید)

### 3️⃣ تنظیم اطلاعات (.env)

`.env` فایل را از `.env.example` ایجاد کنید:

```bash
cp .env.example .env
```

سپس `.env` را ویرایش کنید:

```ini
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_ID=YOUR_ADMIN_ID_HERE
```

### 4️⃣ آماده‌سازی فایل CSV

فایل `data/qa_data.csv` دارای دو ستون است:
- **سوال**: متن سوال
- **جواب**: پاسخ مربوطه

نمونه:
```csv
سوال,جواب
سلام,سلام! خوش آمدی
این ربات چه کاری می‌کند?,این یک ربات پاسخ‌دهی سوالات است
```

### 5️⃣ اجرای ربات

```bash
python main.py
```

## 📖 نحوه استفاده

### کاربران عادی

```
/start      - شروع ربات
/help       - دریافت راهنما
[سوال]      - پرسش هر سوالی
```

### مدیر (Admin)

```
/admin      - نمایش منوی مدیر
/stats      - نمایش آمار
/list       - نمایش تمام سوالات
/reload     - بارگذاری مجدد CSV
```

**پاسخ دادن به سوال بدون جواب:**
1. پیام سوال کاربر را دریافت کنید
2. روی آن Reply کنید
3. جواب تایپ کنید
4. ارسال کنید - جواب خودکار ثبت و به کاربر ارسال می‌شود

## 🔍 نحوه عملکرد

```
شروع
  ↓
کاربر سوالی می‌پرسد
  ↓
ربات در CSV جستجو می‌کند
  ↓
  ├─→ جواب پیدا شد؟ → جواب به کاربر ارسل می‌شود ✅
  │
  └─→ جواب پیدا نشد → سوال به مدیر ارسال می‌شود
        ↓
     مدیر Reply می‌کند
        ↓
     جواب به CSV اضافه می‌شود
        ↓
     جواب به کاربر ارسال می‌شود ✅
```

## ⚙️ تنظیمات سفارشی

برای تغییر تنظیمات، `config.py` را ویرایش کنید:

```python
# ستون‌های CSV
CSV_QUESTION_COLUMN = 'سوال'
CSV_ANSWER_COLUMN = 'جواب'

# حد شباهت برای جستجو (0.0 - 1.0)
SIMILARITY_THRESHOLD = 0.6  # 60% شباهت

# پیام‌های سفارشی
NOT_FOUND_MESSAGE = "متاسفانه پاسخ موجود نیست..."
```

## 🛠️ توسعه و گسترش

### اضافه کردن ویژگی جدید

ساختار ماژولار پروژه، افزودن ویژگی‌های جدید را آسان می‌کند:

1. **ماژول جدید**: فایل جدید در `handlers/` یا `utils/`
2. **کنترل‌کننده جدید**: در `main.py` اضافه کنید
3. **توابع کمکی**: در `utils/` ایجاد کنید

### مثال: اضافه کردن دستور امار بهتر

```python
async def advanced_stats(update: Update, context: ContextTypes.DEFAULT_TYPE):
    # شماری شامل: تعداد سوالات پاسخ‌داده شده، ...
    pass

application.add_handler(CommandHandler("astats", advanced_stats))
```
